# 新座市グリーンサポーター(GS)活動管理アプリ

新座市の緑地整備ボランティア「グリーンサポーター(GS)」の活動運用を管理するWebアプリです。
令和8年度(2026年4月〜2027年3月)のカレンダー上に、毎月「第一水曜日」と「第二以降の木曜日」の活動日が自動で表示されます。

- **誰でも見られるページ ([index.html](index.html))**: 活動カレンダー、活動場所・内容・注意点・写真の確認、感想・改善点の投稿
- **管理者ページ ([admin.html](admin.html))**: パスワードログイン後、活動場所(地図)・内容・注意点の入力、雨天時の中止/延期設定、写真のアップロード

ビルド不要のプレーンHTML/CSS/JSで、データはFirebase(Firestore + Storage + Authentication)に保存します。

## セットアップ手順

### 1. Firebaseプロジェクトを作成

1. [Firebaseコンソール](https://console.firebase.google.com/)で新しいプロジェクトを作成します。
2. 「ビルド > Firestore Database」を有効化します(本番モードで開始してOK)。
3. 「ビルド > Storage」を有効化します。
4. 「ビルド > Authentication」を開き、「Sign-in method」で「メール / パスワード」を有効化します。
5. 「Authentication > Users」で管理者用のメールアドレス・パスワードを1件以上追加します(これが管理者ログイン用アカウントになります)。

### 2. アプリの設定値を反映

1. Firebaseコンソールの「プロジェクトの設定 > 全般 > マイアプリ」でウェブアプリを追加し、表示される`firebaseConfig`の値を確認します。
2. [js/firebase-config.js](js/firebase-config.js) の各値を、自分のプロジェクトの値に書き換えます。
   - この値は公開リポジトリに置いても問題ありません(Firestore/Storageのセキュリティルールでアクセスを制限しているため)。

### 3. セキュリティルールを適用

Firebaseコンソールから、以下のルールを設定してください。

- Firestore Database > ルール: [firestore.rules](firestore.rules) の内容を貼り付けて公開
- Storage > Rules: [storage.rules](storage.rules) の内容を貼り付けて公開

ルールの概要:
- 活動情報(`activities`)は誰でも閲覧可能、編集はログインした管理者のみ
- 感想・改善点(`activities/{date}/feedbacks`)は誰でも投稿・閲覧可能(改ざん防止のため更新・削除は管理者のみ)
- 写真(Storage)は誰でも閲覧可能、アップロードは管理者のみ

### 4. 初回データ登録

1. ブラウザで`admin.html`を開き、手順1で作成した管理者アカウントでログインします。
2. 「初回セットアップ(令和8年度の活動日を一括登録)」ボタンを押すと、令和8年度の活動予定日(第一水曜・第二以降木曜)がFirestoreに自動登録されます。
3. カレンダーから各日をクリックして、活動場所(地図クリックで設定)・活動内容・注意点・写真を登録してください。

### 5. 公開(GitHub Pages例)

このフォルダはそのまま静的ホスティングできます。GitHub Pagesで公開する場合:

1. このリポジトリの Settings > Pages で、公開ブランチ・フォルダ(`/`)を指定します。
2. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセスできるようになります。

## ディレクトリ構成

```
niiza-gs-app/
├── index.html        # 公開カレンダー・活動詳細・感想投稿
├── admin.html        # 管理者ログイン・活動編集パネル
├── css/style.css
├── js/
│   ├── firebase-config.js  # Firebase設定(各自書き換え)
│   ├── calendar.js          # 令和8年度の活動日(第一水曜・第二以降木曜)生成ロジック
│   ├── app.js                # 公開ページのロジック
│   └── admin.js               # 管理者ページのロジック
├── firestore.rules
└── storage.rules
```

## 活動日のルール

各月について以下を活動日とします:

- その月の**第一水曜日**
- その月の**第二木曜日以降のすべての木曜日**(第2・第3・第4・(第5)木曜日)

雨天等で中止・延期する場合は、管理者ページから該当日の「活動状況」を「中止」または「延期」に変更してください。カレンダー上にバッジで表示されます。
